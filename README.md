# 🏀 KBL·WKBL 배트맨토토 누적 대시보드

배트맨토토 **프로토 승부식** 적중결과의 확정 수치만 모아 KBL(남자부)·WKBL(여자부) 농구 경기를 일정 순서로 축적하는 단일 HTML 대시보드입니다. 자바스크립트 없이 순수 CSS(라디오·체크박스)로 화면을 전환하고, 모바일에서 페이지 전체 스크롤 없이 목록만 안에서 스크롤됩니다.

## 수집 범위

| 구분 | 개막 | 집계 마감 | 경기 수 |
|---|---|---|---|
| KBL (남자부) | 2026-10-03 (개막전 부산 KCC vs 창원 LG 등 3경기) | 2026-11-14 종료 경기 | 69경기 |
| WKBL (여자부) | 2026-11-01 (개막전 청주 KB vs 부산 BNK) | 2026-11-14 종료 경기 | 12경기 |

- 출처: `m.betman.co.kr` 프로토 승부식 적중결과 `winrstDetl.do?gmId=G101&gmTs=2601xx`의 `.item-prediction-result.proto` DOM과 페이지 내 원본 데이터(`orgDetlBody`)
- 대상 리그: **KBL·WKBL만**. NBA, EASL, 박신자컵(여자부 컵대회)은 제외했습니다.
- 회차: 프로토 승부식 117~135회차 (경기 번호는 배트맨토토 게임번호)

## 용어 기준

- **마핸 / 플핸**: 홈 기준 마감 핸디캡에서 `-` 기준점을 받은(주는) 팀이 기준점을 넘기면 **마핸**, `+` 기준점 팀이 지켜내면 **플핸**. (마핸승·플핸패 같은 파생 표기는 쓰지 않습니다.)
- **정배 / 역배**: 마감 배당이 낮은(인기) 팀이 이기면 **정배**, 높은 팀이 이기면 **역배**.
- **기준점**: 핸디캡·언더오버 라인이 여러 번 바뀐 경기는 **경기결과 확정(마감) 시점의 마지막 라인**을 사용하고, 변동 이력은 `line_history`에 남겼습니다.
- **승5패**: 배트맨토토 결과 그대로(승 / 5 / 패)를 기록합니다.

## 파일

| 경로 | 설명 |
|---|---|
| `data/matches.json` | 정규화된 경기 데이터(남자부 `mens`, 여자부 `womens`) |
| `raw/rounds_*.json` | 회차별 원본 추출값(DOM + orgDetlBody). 재빌드·검증용 원자료 |
| `build_data.py` | raw → `data/matches.json` 정규화(중복 회차 정리, 마감 라인 선택, 정배/마핸 판정) |
| `build_dashboard.py` | `data/matches.json` → `index.html` 생성 |
| `index.html` | 실제 대시보드(사전 렌더링된 단일 파일) |

## 다시 만들기

```bash
python3 build_data.py        # raw → data/matches.json
python3 build_dashboard.py   # data/matches.json → index.html
```

## 화면

- **남자부 / 여자부** 탭 → **전체 / 구단별** 탭
- 전체: 누적 지표 6종(경기 수·정배 적중률·마핸 달성률·오버 비율·평균 총득점·연속 흐름) + 개막전부터 누계 표
- 구단별: 구단 패널 → 선택한 구단의 전적·연속 스트릭·정배/역배 전적·최근 5경기·경기별 카드
